# Glossary

**Deck (Bộ từ)**: A named group of words, possibly with sub-decks. Each deck has one study language.

**Word (Từ)**: One vocabulary item: term, meaning, examples, tags, and its own review schedule.

**Study language**: The language a deck's words are in. It drives pronunciation. A user can study any number of languages, one per deck.

**Share link (Link chia sẻ)**: A revocable link that lets any signed-in user add a copy of a deck to their library.

**Deck copy (Bản sao)**: What a recipient gets from a share link: the deck, its sub-decks and their words, with fresh review progress. It does not follow later changes to the original.

**Session (Buổi học)**: One run through a queue of words. Only one session is open at a time; starting a new one ends the old one.

**Paste list (Dán danh sách)**: Adding many words at once by pasting lines of `term - meaning`.
